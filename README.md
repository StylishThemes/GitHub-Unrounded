## GitHub-Unrounded
> Remove obnoxious/destructive border-radii on GitHub

This style is retired. [GitHub Dark](https://github.com/StylishThemes/GitHub-Dark) has it built in as the "Unrounded labels and avatars" option. For other themes, use [GitHub Custom Border Radii](https://github.com/StylishThemes/Feature-Override-Styles/blob/master/github-custom-border-radii.user.css).
